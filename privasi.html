Kebijakan Privasi KantongKu

Berlaku sejak 3 November 2026

KantongKu adalah aplikasi pencatat uang masuk dan keluar. Privasi kamu penting, jadi kebijakan ini dibuat singkat dan jelas.

Data yang kamu catat

Semua catatan (jumlah, kategori, tanggal, catatan, dan target tabungan) disimpan hanya di perangkat kamu, di penyimpanan browser. Data ini tidak dikirim ke server kami dan tidak bisa kami lihat.

Yang tidak kami lakukan

  • Tidak ada akun, pendaftaran, atau login.
  • Tidak mengumpulkan nama, email, nomor HP, atau lokasi.
  • Tidak memasang iklan atau pelacak pihak ketiga.
  • Tidak menjual atau membagikan data kamu.

Layanan pihak ketiga

  • Google Fonts: aplikasi memuat font dari Google Fonts. Saat itu Google dapat menerima alamat IP perangkat kamu sesuai kebijakan privasi Google.
  • GitHub Pages: aplikasi di-host di GitHub Pages. GitHub dapat mencatat log akses standar (misalnya alamat IP) sesuai kebijakan privasi GitHub.

Cadangan dan penghapusan data

Karena data ada di perangkat kamu, data hilang jika data browser atau aplikasi dihapus, atau perangkat diganti. Gunakan tombol Salin semua data (CSV) untuk membuat cadangan. Kamu bisa menghapus catatan satu per satu di aplikasi, atau menghapus semuanya lewat pengaturan data situs di browser.

Mode offline

Agar bisa dipakai tanpa internet, aplikasi menyimpan salinan file-nya (halaman, ikon, dan font) di perangkat kamu.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan ditampilkan di halaman ini beserta tanggal berlakunya.
